# SherlockOS architecture

A macOS-style desktop that runs in the browser. React 19 + Vite + zustand + framer-motion.

```
src/
  main.jsx, App.jsx          HashRouter: "/" boot (GRUB) -> "/plymouth" splash -> "/desktop"
  pages/                     Boot.jsx, Plymouth.jsx (boot sequence)
  os/                        the operating system core
    windowStore.js           window manager (zustand): wm.open/close/focus/minimize/...
    Window.jsx               window chrome, drag, resize, snap, animations
    apps.js                  app registry (id, name, icon, lazy component, sizes, chrome)
    fs.js                    virtual filesystem (manifest + localStorage ops log)
    open.js                  openPath(path) / openUrl(url) - "open with default app"
    settingsStore.js         persisted settings (theme, accent, wallpaper, dock...)
    ui.js                    context menu, notifications, shell overlay state
    theme.css                design tokens (CSS variables) + shared primitives
    Desktop.jsx              composes wallpaper, icons, windows, menubar, dock, overlays
    shell/                   MenuBar, Dock, DesktopIcons, DockOverlays, SystemOverlays
  apps/<id>/index.jsx        one folder per app (default export = component)
  content/home/              text files mirrored into the virtual home (~ = /home/sherlock)
  assets/                    images, documents (scanned into the virtual filesystem)
  data/fileSystemData.js     GENERATED by scripts/generateFileSystemData.js (npm run generate-fs)
```

## Window manager — `import { wm, useWindows, useWindow } from "../../os/windowStore"`

- `wm.open(appId, props?, opts?)` -> windowId. Singleton apps focus the existing window and merge
  `props` (and bump `propsVersion`); multi-instance apps reuse a window whose `props.path` matches.
  `opts`: `{ title, size:{w,h}, position:{x,y}, maximized }`.
- `wm.close(id)`, `wm.focus(id)`, `wm.minimize(id)`, `wm.toggleMaximize(id)`, `wm.setTitle(id, title)`,
  `wm.toggleApp(appId)` (dock behaviour), `wm.closeAll(appId?)`, `wm.cycle(dir)`, `wm.setSnap(id, "left"|"right"|null)`.
- `useWindows(selector)` — state `{ windows: [{id, appId, title, props, x,y,w,h,z, minimized, maximized, snap, closing}], activeId }`.
- `useActiveWindow()`, `useActiveMaximized()`, `isMobile()`, `MENUBAR_H`.

## Apps

An app component receives `{ windowId, propsVersion, ...props }`. Props can change while mounted
(e.g. Finder is asked to show another `path`): react to them with an effect keyed on `propsVersion`.

`chrome: "default"` — the window draws a 38px title bar. Just fill the content area.
`chrome: "unified"` — no title bar; traffic lights float at top-left. The app renders its own top bar:
`<div className="os-toolbar" data-window-drag>…</div>` (52px, already padded 88px on the left for the
traffic lights). Any element with `data-window-drag` drags the window; buttons/inputs inside are
automatically excluded (or use `data-no-drag`). Sidebars that reach the top of the window must leave
52px free at their top (and can carry `data-window-drag` on that spacer).

The app root must fill its container (`height: 100%`, `display:flex; flex-direction:column`, `min-height:0`)
and manage its own scrolling (`className="os-scroll"`). Windows get as narrow as ~360px (phones: every
window is full-screen) — layouts must adapt (collapse sidebars with container queries / ResizeObserver,
NOT viewport media queries, since the window width is what matters).

## Filesystem — `import fs, { useFs, HOME, DESKTOP, TRASH, kindOf, formatSize, join, dirname, basename, extname, resolve, tilde, isTextKind } from "../../os/fs"`

Sync, in-memory. `fs.stat(p)` -> `{path,name,type:"dir"|"file",size,mtime,kind,ext,builtin,trashedFrom}|null`,
`fs.list(dir,{hidden})`, `fs.walk(dir)`, `fs.search(q, root)`, `fs.exists/isDir/isFile`,
`fs.url(p)` (URL of a binary asset or null), `fs.thumb(p)` (small image thumbnail URL),
`await fs.readText(p)`, `fs.writeText(p, text)`, `fs.createFile(dir, name, text)`, `fs.mkdir(p,{unique})`,
`fs.move(from,to)`, `fs.rename(p,newName)`, `fs.copy(from,to)`, `fs.trash(p)`, `fs.restore(p)`,
`fs.remove(p)`, `fs.emptyTrash()`, `fs.reset()`. Call `useFs()` in any component that renders fs data so
it re-renders on change. Kinds: image, pdf, markdown, text, code, audio, video, link (`.webloc`, JSON
`{"url":…}`), app (`.app`, JSON `{"app":id,"props":{}}`), unknown.

`import { openPath, openUrl, openExternal } from "../../os/open"` — always open files through `openPath`.

## Settings — `import { useSettings, settings, ACCENTS } from "../../os/settingsStore"`

`useSettings(s => s.accent)`, `settings.set({ accent })`. Keys: theme, accent, wallpaper (fs path or URL),
wallpaperFit, dockSize, dockMagnify, dockAutoHide, reduceMotion, transparency, sound, volume,
brightness, showDesktopIcons, clock24h, skipBoot.

## UI services — `import { contextMenu, notify, ui, useUI } from "../../os/ui"`

- `onContextMenu={(e) => contextMenu(e, [{ label, icon?, shortcut?, danger?, disabled?, checked?, onClick, submenu? }, { separator: true }])}`
- `notify({ title, body, icon?, appId?, onClick? })`
- `ui.setOverlay("spotlight"|"launchpad"|"controlCenter"|"notificationCenter"|"missionControl"|null)`, `ui.toggleOverlay(name)`.

## Styling rules

- Use the CSS variables from `os/theme.css` (`--bg-window`, `--bg-content`, `--bg-sidebar`, `--bg-toolbar`,
  `--bg-elevated`, `--bg-input`, `--bg-hover`, `--bg-active`, `--glass`, `--glass-strong`, `--glass-blur`,
  `--border`, `--border-strong`, `--text`, `--text-2`, `--text-3`, `--accent`, `--accent-soft`,
  `--accent-text`, `--danger`, `--success`, `--warning`, `--radius`, `--radius-sm`, `--font-ui`,
  `--font-mono`, `--ease-out`, `--dur-fast`, `--dur`, `--dur-slow`, `--shadow-pop`). Never hard-code
  theme colors: both dark and light themes must work.
- Primitives: `.os-toolbar`, `.os-toolbar-title`, `.os-toolbar-spacer`, `.os-btn`, `.os-btn--primary`,
  `.os-icon-btn`, `.os-input`, `.os-scroll`, `.os-spinner`, `.os-selectable` (text is unselectable by default).
- Prefix every class with the app id (`.finder-…`, `.safari-…`) — all CSS is global.
- Animate only `transform` and `opacity`. Respect `settings.reduceMotion`.
- Icons: `react-icons` (prefer the `react-icons/lu` or `react-icons/io5` sets for a consistent look).

## Deploying

`npm run deploy:live` builds and publishes `dist/` to the `os-live` branch of
`psychoSherlock/psychosherlock.github.io`, which GitHub Pages serves at https://psychosherlock.github.io.
