## Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| `Ctrl` + `K`, `Ctrl` + `Space`, `Alt` + `Space` or `/` | Spotlight search |
| `F3` or `Ctrl` + `↑` | Mission Control |
| `Alt` + `` ` `` or `Ctrl` + `` ` `` | Switch between apps (hold the modifier, press again to advance) |
| `Alt` + `W` | Close the active window |
| `Alt` + `M` | Minimize the active window |
| `Alt` + `Enter` | Maximize / restore the active window |
| `Esc` | Close Spotlight, Launchpad or Mission Control |

Spotlight also does maths (`2^10 / 4`), runs system actions (dark mode, lock
screen, empty trash, change wallpaper, restart) and searches the web.

## On the desktop

- Double-click an icon to open it; drag to rearrange.
- Drag across empty wallpaper to select several icons.
- Press `Enter` to rename the selected icon, `Delete` to move it to the Trash.
- Right-click the wallpaper for new folders, text files, Clean Up and more.

Your changes are saved in this browser, so the desktop stays the way you leave it.
